# Risk Data Platform

Production-grade foundation for a commodities trading risk data platform.

## Tech Stack
- .NET 8 + C# 12
- Microsoft Orleans 10.x
- .NET Aspire
- Apache Arrow (IPC file format with dictionary encoding)
- DuckDB (in-process columnar query engine)
- SignalR (real-time notifications)
- AWSSDK.S3 (object storage)
- SQL Server (Orleans grain state)
